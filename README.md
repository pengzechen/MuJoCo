# MuJoCo 网球抓取小车

这是一个自包含的 MuJoCo Python 示例，包含：

- 一个带自由运动底盘的三轮小车
- 前左、前右两个独立主动轮
- 车尾中间一个被动万向轮
- 大臂、小臂、夹爪三个舵机
- 一块铺满整个场地的棋盘纹理地板
- 一个放在地面上的可碰撞网球，球地摩擦可调
- 一圈接近小车高度的围挡，防止网球滚出场地
- 可编辑的舵机动作序列，以及自动夹球 weld

## 安装和运行

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

如果系统禁止全局 pip 安装，可以先创建虚拟环境：

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## 操作

- `W` / `S`：小车前进 / 后退
- `A` / `D`：差速左转 / 右转
- `1`：加载并执行 `pick_ball` 序列
- `2`：加载并执行 `home` 序列
- `Space`：暂停 / 继续
- `R`：释放已经抓住的网球（张开夹爪，球会掉下来）
- `B`：网球回到初始位置并静止（球被撞飞、或者被压到地板下面之后可以用它复位，同时会松开夹爪）
- `[` / `]`：降低 / 提高小球与地板的滑动摩擦，每次 `0.1`
- 鼠标拖动左下角滑块：实时摆大臂 / 小臂 / 夹爪
- `P`：把当前滑块姿态追加保存到 `sequences.json` 的 `manual` 序列
- `3`：回放 `manual` 序列

## 调整小球与地板的摩擦

小球与地板的接触由 `scene.xml` 里的 `ball_floor` 接触对单独控制，改它不会影响车轮和其他接触。三种改法：

- 运行中按 `[` / `]`，当前值显示在左上角
- 启动时指定：`python main.py --ball-floor-friction 0.4`
- 改默认值：`main.py` 顶部的 `BALL_FLOOR_FRICTION`

有两个 MuJoCo 的规则容易踩：

- 没有写进接触对的接触，摩擦系数取两个 geom 的**逐元素最大值**，所以地板上的 `2.2` 会盖过小球自己的 `1.8`——这正是需要这个接触对的原因
- `pair_friction` 用的是接触内部的 5 元组布局 `(切向1, 切向2, 扭转, 滚动1, 滚动2)`，和 geom 的 `(滑动, 扭转, 滚动)` 不是一回事，而且是**原样**写进接触，所以代码把滑动值同时写进了两个切向槽

接触对默认 `condim="3"`，只有滑动摩擦起作用，小球在地上会一直滚下去。改成 `condim="6"` 会带来滚动阻力，但多出来的阻力自由度会把球推出夹爪够得着的范围，`pick_ball` 就抓不稳了。

`pick_ball` 只在滑动摩擦大约 `1.8 ~ 2.2` 时抓得住，默认值 `2.2` 就取在这个区间中间：

- 低于 `1.8`：球会从夹爪底下滑走，差几厘米够不到
- 高于 `2.5`：手指会把球压进地板，球心越过 6 cm 厚的板底后接触消失，球直接掉下去

## 用滑块摆姿态并保存

窗口左下角有三个滑块（大臂 / 小臂 / 夹爪），用鼠标拖动就能实时摆姿态：

- 滑块控制的是**指令值**（`data.ctrl`），量程直接取自模型的 `ctrlrange`，没有写死
- 不拖动时滑块会跟着舵机走，所以按 `1` / `2` 回放序列时滑块自己会动
- 一旦按下滑块就会**取消正在播放的序列**，交还手动控制（两者都要写 `ctrl`，不接管就会每帧互相覆盖）
- 拖动中鼠标可以离开滑块所在那一行，x 方向继续跟随，两端自动钳位
- 鼠标在窗口外松开也能正常结束拖动（主循环会轮询鼠标键状态兜底）

摆好一个姿态后按 `P`，会把当前三个舵机值**追加**成 `sequences.json` 里 `manual` 序列的一步：

```json
"manual": [
  {"shoulder": -1.1, "elbow": -1.35, "gripper": 0.035, "duration": 0.6}
]
```

重复「拖 → 按 `P`」就能攒出一条动作序列，按 `3` 回放。每步的 `duration` 默认 `0.6` 秒（`main.py` 顶部的 `SAVED_STEP_DURATION`），想改节奏直接编辑 json。

保存会用统一格式重写整个 `sequences.json`：布局不变（每个 step 一行、键顺序不变），但 `-1.10` 这类尾随零会被规范成 `-1.1`，数值不变。

## 编辑舵机序列

直接编辑 `sequences.json`，每一步包含三个舵机目标角度和停留时间：

```json
{
  "shoulder": 0.55,
  "elbow": -1.25,
  "gripper": 0.015,
  "duration": 0.7
}
```

角度单位是弧度；夹爪是滑动舵机，范围是 `0` 到 `0.10` 米，数值越小表示夹紧。程序在按下 `1` 或 `2` 时重新读取 JSON，因此修改文件后无需修改代码。

## 模型说明

场景在 `scene.xml` 中定义。当前底盘使用前双轮差速驱动、后中置万向轮支撑，适合先验证小车和机械臂控制流程。若要提高底盘运动精度，可以把主动轮替换为带轮地切向摩擦方向的轮胎 mesh，并加入更完整的轮地动力学。
